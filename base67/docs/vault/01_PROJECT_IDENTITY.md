# 01 Project identity

- **Name:** BASE 67. Nothing else. The old project name must not appear in the app, UI, documents' titles, package display name or release.
- **What it is:** a 2D, offline-first, portrait-first Android game built with Flutter. The player commands a four-person crew and builds one persistent Mars base over a 15-level, five-chapter campaign.
- **Audience:** children aged 10-14. Understandable, fair, accessible, never manipulative.
- **Competition:** NASA Space Apps 2026, challenge "Build a Junior Astronaut Mission Trainer". Real NASA data is used wherever it exists and is labelled. Everything else is clearly labelled as game design.
- **Purpose:** teach, by playing, that surviving on Mars is about trade-offs: every choice helps one thing and hurts another.
- **Not:** not a multiplayer game, not an online game, not a monetised game, not a copy of any existing game, not a realistic engineering simulator.
- **Characters:** four astronauts with fixed roles (Commander, Engineer, Scientist, Medic) and one helper, Dave, the AI assistant. Astronaut art is original, bean-shaped and drawn in code. No assets, names or characters from existing games.
- **Truth about testing:** the game has not been tested with students. Never claim learning outcomes.
- **Where the full design lives:** `docs/GAME_BRIEF.md` (source of truth) and `docs/BASE_67_Game_Design_Document.docx`.
