# 11 Glossary

| Term | Meaning |
|---|---|
| BASE 67 | The game. The only allowed name |
| Sol | A Martian day, 24.6597 hours (NASA fact `sol_hours`) |
| Tick | One hour of Martian simulation time (unless documented otherwise) |
| Tau | How much dust blocks sunlight. About 5 percent of sunlight gets through at tau 3 (NASA data) |
| mSv | Millisievert, a unit of radiation dose |
| SEP | Solar particle event, a burst of radiation from the Sun |
| NASA DATA / GAME VALUE / DERIVED | The three data classes (see `05_DATA_GOVERNANCE.md`) |
| Fact id | The key of a value in `nasa_data.json` (for example `solar_irradiance`) |
| Data pack | The original JSON files in `assets/data/` (read-only) |
| `extra/` | `assets/data/extra/`, where new GAME VALUE files live |
| Dave | The in-game AI helper from the prologue (hints and explanations) |
| Mission Control | The radio voice that warns about events |
| Home Base | The persistent base screen and campaign hub |
| Campaign Map | The 15-level path in five chapters |
| Persistent base | One base for the whole campaign; never reset by a level |
| Real-world timer | Construction/research time stored as UTC timestamps; separate from sols |
| Vault | This folder: `docs/vault/` |
| Prompt | One of eight Codex instruction files in `docs/prompts/` |
